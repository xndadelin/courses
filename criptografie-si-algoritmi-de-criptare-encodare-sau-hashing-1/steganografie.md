---
description: >-
  Steganografia este practica de a ascunde intr-un fisier, imagine, documente,
  informatii care nu ar putea fi evidente unei persoane.
---

# 🧙 Steganografie

| Instrument                  | Descriere                                                               | Instalare                                                                                      | Comenzi utile                                                                                                       |
| --------------------------- | ----------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| **Binwalk** 📂🔍🛠️         | Caută fișiere binare pentru date și fișiere ascunse.                    | `apt install binwalk`                                                                          | <p><code>binwalk fisier</code></p><p><code>binwalk -e fisier</code></p><p><code>binwalk --dd ".*" fisier</code></p> |
| **Foremost** 🗃️🔎🔧        | Recuperează fișiere bazate pe anteturi și structuri interne.            | `apt install foremost`                                                                         | `foremost -i fisier`                                                                                                |
| **Exiftool** 🖼️🔍📄        | Afișează metadatele fișierelor.                                         | [Link oficial](https://exiftool.org/)                                                          | `exiftool fisier`                                                                                                   |
| **Exiv2** 🏷️🔍🗂️          | Afișează metadatele fișierelor, similar cu Exiftool.                    | `apt install exiv2`                                                                            | `exiv2 fisier`                                                                                                      |
| **File** 📂❓🔍              | Determină tipul unui fișier.                                            | Preinstalat                                                                                    | `file fisier`                                                                                                       |
| **Strings** 🔡🔍📜          | Extrage șiruri de caractere din fișiere binare.                         | `apt install binutils`                                                                         | <p><code>strings -n 6 fisier</code></p><p><code>strings -e l -n 6 fisier</code></p>                                 |
| **cmp** 🔄🆚📊              | Compară două fișiere bit cu bit.                                        | Preinstalat                                                                                    | `cmp original.jpg stego.jpg -b -l`                                                                                  |
| **identify** 🖼️📋🔍        | Verifică tipul și integritatea fișierelor imagine.                      | `apt install imagemagick`                                                                      | `identify -verbose fisier`                                                                                          |
| **Steghide** 🖼️🔐📂        | Detectează și extrage date ascunse în imagini/audio (JPEG, BMP, WAV).   | `apt install steghide`                                                                         | <p><code>steghide info fisier</code></p><p><code>steghide extract -sf fisier</code></p>                             |
| **Zsteg** 🖼️🔍🔢           | Detectează date ascunse în fișiere PNG/BMP.                             | `gem install zsteg`                                                                            | `zsteg -a fisierzsteg -E b4,bgr,msb,xy fisier.png`                                                                  |
| **stegoVeritas** 📷🛠️🔍    | Analizează și extrage date ascunse din fișiere imagine.                 | `pip install stegoveritas`                                                                     | `stegoveritas.py fisier.jpg`                                                                                        |
| **Stegsolve** 🎨🖼️🔍       | Aplică filtre de culoare pentru a detecta mesaje ascunse în imagini.    | [https://wiki.bi0s.in/steganography/stegsolve/](https://wiki.bi0s.in/steganography/stegsolve/) | Deschide imaginea și folosește butoanele `< >`                                                                      |
| **ffmpeg** 🎵📂🔎           | Verifică integritatea fișierelor audio.                                 | `apt install ffmpeg`                                                                           | `ffmpeg -v info -i fisier.mp3 -f null -`                                                                            |
| **Wavsteg** 🎵🔐📁          | Extrage date ascunse din fișiere WAV folosind LSB.                      | [https://github.com/pavanchhatpar/wav-steg-py](https://github.com/pavanchhatpar/wav-steg-py)   | python wav-steg.py -r -s opera\_steg.wav -o data\_steg.txt -n 2 -b 10                                               |
| **Deepsound** 🎵🔐🔊        | Caută informații ascunse criptate cu AES-256 în fișiere audio.          | [https://github.com/Jpinsoft/DeepSound](https://github.com/Jpinsoft/DeepSound)                 | Deschide fișierul audio în aplicație                                                                                |
| **Sonic Visualizer** 🎵📊🔍 | Analizează conținutul fișierelor audio pentru a detecta mesaje ascunse. | [https://www.sonicvisualiser.org/](https://www.sonicvisualiser.org/)                           | Folosește spectrograma audio.                                                                                       |
